# Ayushman Singh — Developer Portfolio Website 🚀

A modern, responsive, high-performance developer portfolio built for **Ayushman Singh**, Full-Stack Software Engineer specializing in **React.js, Next.js, Node.js, MongoDB**, and **Real-Time Video Streaming (RTSP/FFmpeg HLS)**.

---

## 🌟 Highlights & Features

- **⚡ Modern Tech Stack**: Built with Vite, React 19, and Tailwind CSS v4.
- **💼 Production Experience Focus**: Highlights internship at **Genius Vision Digital (GVD)**, Next.js migrations, and RESTful API architecture.
- **🎥 Real-Time Media Architecture**: Showcases low-latency RTSP camera streaming and FFmpeg HLS conversion.
- **📂 Real Projects Showcase**:
  - **QR Scanner & Camera Playback System** (Dispute resolution with CCTV video linking)
  - **React Admin Dashboard** (TanStack Query, protected routing, API caching)
  - **Social Echo** & **E-Commerce Storefront**
  - **Task & Team Management Hub**
  - **Modern React Landing Page**
- **🏆 Certifications & Exhibitions**: Apna College (DSA Java), GRAStec (MERN), Deloitte Data Analytics, and TechXplore Exhibition.
- **✉️ Interactive Contact Section**: Direct contact cards, one-click copy email button, and message form with celebration confetti!
- **📱 Fully Responsive**: Flawless experience across mobile phones, tablets, laptops, and ultra-wide displays.
- **🎨 Modern Dark UI**: Glassmorphism, glowing ambient accents, smooth scrolling, and developer terminal preview.

---

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```

## 🌐 Deploy to Vercel / Netlify / GitHub Pages

This project is ready to deploy with one click on **Vercel** or **Netlify**:
1. Push your repository to GitHub: `https://github.com/ayushman1729/portfolio`
2. Import repository on [Vercel](https://vercel.com) or [Netlify](https://netlify.com)
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
